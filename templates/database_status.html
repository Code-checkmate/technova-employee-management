Configuration & Credential Safety

Safe Endpoint Switching

To switch between Amazon RDS for MySQL and Amazon Aurora MySQL, update the target endpoint in your environment configuration (.env) or EC2 systemd service: 

# Example Amazon RDS Endpoint
MYSQL_HOST=technova-db.c9akxxxxxx.us-east-1.rds.amazonaws.com

# Example Amazon Aurora Cluster Endpoint
MYSQL_HOST=technova-aurora-cluster.cluster-c9akxxxxxx.us-east-1.rds.amazonaws.com

Credential Hygiene Guarantees

  • Zero credential exposure: Passwords and raw database connection strings are never rendered in templates, transmitted in JSON health payloads, or logged to disk.
  • Parameterized execution: All application database queries use SQLAlchemy parameter binding, preventing SQL injection vulnerabilities.
  • Truthful connectivity reporting: If the database host or network is unreachable, the system truthfully returns a non-200 HTTP code without masking failure.
  • Non-destructive initialization: Application startup will never DROP, TRUNCATE, or overwrite production employee data.
